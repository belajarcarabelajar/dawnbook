# Book covers and share cards: renderer, gate and revert

Moved verbatim from `GEMINI.md` on 2026-11-15, when the always-loaded instruction files were compacted under the 150k-character limit. `GEMINI.md` keeps the binding summary of each rule and points here; each heading below names the `GEMINI.md` section the text belongs to. Read this file before the work its pointer in `GEMINI.md` names. In the moved text, "this section" and "this file" mean the `GEMINI.md` section named in the heading.

## From section 27 (Book Covers and Share Cards (Added 2026-10-21))

- **Renderer:** `scripts/og/cards.ts` and `scripts/render-og-cards.ts`, run inside `bun run build` with satori and `@resvg/resvg-js` (pinned devDependencies, fonts from `@fontsource`), so CI needs no browser and the same inputs give the same bytes. The title size is the largest of 58 to 30 px at which every word fits the 466 px panel and the title wraps into at most 4 lines (widths measured with `opentype.js`, with a line break allowed after a hyphen as satori does): Syne is wide, and at weight 800 the word "Perkembangan" alone was 721 px at 58 px. Every `new Resvg(...)` MUST pass `font: { loadSystemFonts: false }`: the SVGs hold no text (satori outlines it), and the default system-font scan made each card about 90 ms slower. Measured 2026-10-21 on this laptop: 809 cards for 59 books in 46 s of a 53 s `bun run build` (107 s for the cards before the fix), 93 MB under `output/og/`.
- **Gate:** `HEAVY_LOCAL=check-covers bun run check:covers [--book <slug>]`, also the first step of `bun run build`, so a book without a valid cover fails the build and therefore the deploy. Rule ids: `missing-cover`, `no-svg-root`, `bad-viewbox` (must be `0 0 630 630`), `too-large` (40 KB), `forbidden-element` (`text`, `tspan`, `textPath`, `style`, `script`, `foreignObject`, `image`, `a`, `iframe`, `video`, `audio`), `external-ref` (only `#id` references), `event-attr`, `emoji`, `render-error`, and `missing-glyph` (a title or author character the card fonts cannot draw; satori would drop it silently. Syne covers latin, latin-ext and greek; Epilogue, used for the book title above a chapter title and for the author, has no greek).
- **Telegram caches link previews per URL.** A link shared before its card existed keeps the old preview; Telegram's `@WebpageBot` refreshes it when sent the URL (from Telegram's documentation, not tested here).
- **Revert:** remove this section and Phase B step 9 in `MDBOOK_SYSTEM_RULES.md`; delete `scripts/og/`, `scripts/check-covers.ts`, `scripts/render-og-cards.ts`, their tests, the cover check and the render step in `scripts/build.ts`, the `ogImage`/`ogImageAlt` options, `shareCardUrl` and the missing-card check in `scripts/inject-gating.ts`, the `check:covers` and `og:preview` scripts and the five devDependencies (`satori`, `@resvg/resvg-js`, `@fontsource/syne`, `@fontsource/epilogue`, `opentype.js`) in `package.json`, and run `bun install` to update `bun.lock`; the `cover.svg` files can stay.
