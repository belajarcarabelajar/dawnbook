Moved verbatim from `GEMINI.md` on 2026-11-15, when the always-loaded instruction files were compacted under the 150k-character limit. `GEMINI.md` keeps the binding summary of each rule and points here; each heading below names the `GEMINI.md` section the text belongs to. Read this file before the work its pointer in `GEMINI.md` names. In the moved text, "this section" and "this file" mean the `GEMINI.md` section named in the heading.

## From section 24 (Heading Anti-Colon Rule (No "Judul: Subjudul" Headings))

- **Owner-approved one-time exception to section 1 (2026-10-11):** the owner allowed editing ONLY the `title` line of `books/metakognisi/book.toml`, `books/pembelajaran-multidisiplin/book.toml`, and `books/quarter-life-crisis/book.toml` to remove the colon. Every other `book.toml` edit stays forbidden, including any other key in those three files.
- **Structure gate (added 2026-10-24):** `bun run build` runs `scripts/check-book-structure.ts` over every book (slugs starting with `_` are skipped) before the mdBook builds and exits 1 on any problem: the chapter title must be a level-2 heading equal to its SUMMARY title, no section heading may repeat in two chapters of a book (this gate fails at 2, stricter than the 3 of `check-repeated-headings`, matching section 21), every opener's first sentence must survive the 155-character meta cut (section 8), plus the checker's other rules (SUMMARY and disk agree, no stray markdown in `src/`, `book.toml` description of 100 to 160 characters, no em dash, emoji or "Anda", link targets that resolve), and a book with no chapters fails. Run it alone with `HEAVY_LOCAL=check-structure bun run check:structure`, or for one book with `HEAVY_LOCAL=check-structure bun run scripts/check-book-structure.ts <slug>`. Revert: remove the `runStructureGate` call in `scripts/build.ts` and the `check:structure` script in `package.json`.
- **Verification (mandatory):** `HEAVY_LOCAL=check-headings bun run scripts/check-heading-colons.ts` (read-only detector, exit 1 on any violation, exit 0 when clean). It also lists every `heading-colon-ok` marker so exemptions stay visible. The same check runs inside `bun run build` (the build exits 1 on a colon heading, so deploy is gated too) and as `bun run check:headings`. It scans ATX headings (also inside blockquotes and list items), setext headings, single-line `<h1>` to `<h6>` headings, and counts the fullwidth colon (U+FF1A). Math is stripped by the Pandoc rule: the opening `$` must not be followed by a space and the closing `$` must not be preceded by a space or followed by a digit, so `Harga $5: murah dan $10` is a violation. The title-quality ruler is `bun run scripts/measure-heading-quality.ts <slug> --base <ref>` (dev tool, not part of the build).
